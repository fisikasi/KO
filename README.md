# KO Basket

Hasierako PWA egitura, React + TypeScript + Supabase erabiliz.

## Lehen urratsak

1. Sortu Supabase proiektu berri bat.
2. SQL Editor-en exekutatu `supabase.sql`.
3. Kopiatu `.env.example` fitxategia `.env` izenarekin.
4. Bete `VITE_SUPABASE_URL` eta `VITE_SUPABASE_ANON_KEY`.
5. Terminalean:

```bash
npm install
npm run dev
```

## Oraingo bertsioak daukana

- Saioa hasi
- Kontua sortu, erabiltzaile-izena + emaila + pasahitza
- Lehiaketen pantaila
- Bigarren Nazionala Gizonezkoak egituratzeko oinarria
- Taldeak lehiaketa bakoitzaren barruan independenteak
- Jardunaldi baliodunak / KO-rako baliogabeak
- Erabiltzaile bakoitzak aukera bakarra jardunaldi bakoitzeko
- Erabiltzaile batek talde bera ezin du berriro erabili lehiaketa berean
